# Их Юань гүрэн — кино маягийн веб презентац

ШУТИС, I курс, «Монголын түүх». 20 слайд, HTML/CSS/JS + GSAP + SVG газрын зураг.

**Нээх:** `index.html`-ийг хөтчид нээнэ (интернэт шаардлагагүй).

**Удирдлага:** ← → / Space · Home / End · N — илтгэгчийн тэмдэглэл · S — эх сурвалж · M — хөдөлгөөн багасгах · F — бүтэн дэлгэц. Утсанд зүүн/баруун шудрана.

**Бүтэц**
- `index.html`, `style.css`, `script.js` — презентац
- `data/map.js` — Natural Earth 1:50m эрэг + бүдүүвч хил хязгаар
- `lib/gsap.min.js` — GSAP 3.12.5
- `fonts/` — Cormorant Garamond, IBM Plex, Noto Serif SC, Noto Sans Mongolian (SIL OFL)
- `research-brief.md` — судалгааны товчлол, ном зүй, storyboard

Хил хязгаар, Хубилайн дүрс, цаасан мөнгө, Дайдугийн төлөвлөлт нь бүдүүвч сэргээлт бөгөөд түүхэн нотолгоо биш.
